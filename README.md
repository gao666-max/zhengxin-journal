# 正心 · 觉察日记

聊天式觉察日记：跟 AI 聊几句 → 自动提取睡眠 / 饮食 / 情绪 / 记账 / 感恩 → 写进 Obsidian 每日日志，支持复盘和定时提醒。

## 功能
- **聊天式记录**：不用填表，聊几句，DeepSeek 自动提取结构化字段
- **记账**：聊到花了/赚了多少钱就自动记，按分类统计
- **复盘**：点「复盘」看月度/季度汇总（记账分类、总收支、平均精气神等）
- **定时提醒**：每天到点弹 Windows 通知，点开就记

## 安装
1. 装依赖：
   ```
   pip install -r requirements.txt
   ```
2. 配 config.json（也可启动后在页面「设置」里填）：
   ```json
   {
     "deepseek_api_key": "sk-...",
     "obsidian_vault": "你的Obsidian每日日志目录（留空则写到本地 每日日志/）"
   }
   ```
3. 启动：双击 `启动正心.bat`，或：
   ```
   python -m uvicorn main:app --host 127.0.0.1 --port 8900
   ```
   浏览器打开 http://127.0.0.1:8900

## 定时提醒（Windows）
双击 `安装提醒.bat`（每天 21:00 弹通知；改时间改文件里的 `/ST 21:00`）。

## 数据
- 每日状态存 `data/YYYY-MM-DD.json`（git 忽略）
- 日记写进 Obsidian 每日日志，用 `<!-- 正心觉察 start/end -->` 包裹，增量合并不覆盖
